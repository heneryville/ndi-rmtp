# Snow Springs Stake Streaming

A building appliance that streams ward sacrament meetings from the chapel camera
to each ward's YouTube channel. It's run by stake volunteers, not by the Church.

## What it does

Wards that connect their YouTube channel get these automatically:

- **Start:** creates the week's broadcast, then goes live.
- **Stop:** ends the broadcast.
- **After 7 days:** deletes recordings the appliance created, unless one is marked
  **Keep**. It never touches other videos.

A ward that doesn't connect can still stream with a pasted stream key.

## Connecting a ward

1. On the appliance, open **Ward setup** and choose **Connect YouTube**.
2. Go to [google.com/device](https://www.google.com/device) and enter the code shown.
3. Sign in as the ward's YouTube account and choose its channel.

To disconnect, use **Disconnect YouTube** on the same page, or
[Google Account permissions](https://myaccount.google.com/permissions).

## Privacy

- **Access:** the `youtube` scope, used only to read the channel's name and ID,
  use its stream key, create, end and list broadcasts, and delete recordings the
  appliance created.
- **Storage:** the token, channel ID, stream key and keep list are stored only on
  the appliance in the building. There's no server or cloud service.
- **Sharing:** none. Google user data isn't sold, transferred, used for ads, or
  used to train AI. Use follows the
  [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
  including Limited Use.
- **Visibility:** the appliance's pages are reachable only on the building network,
  and keys and tokens are never displayed.
- **Removal:** Disconnect revokes access and erases the token. Recordings stay on
  the channel until deleted.
